## 3. База данных (SQLite)

Одна главная таблица:

```sql
CREATE TABLE entries (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  kind TEXT NOT NULL CHECK(kind IN ('work','dyzur')),
  oddzial TEXT NOT NULL,
  start_ts TEXT NOT NULL,          -- ISO 'YYYY-MM-DD HH:MM', локальное время Europe/Warsaw
  end_ts TEXT,                     -- NULL = смена/дежурство ещё открыто
  source TEXT NOT NULL DEFAULT 'bot',  -- 'bot' | 'manual' (исправление задним числом)
  created_at TEXT NOT NULL
);
```

Правила:
- Одновременно может быть открыт максимум **один** entry (любого kind). Перед вставкой проверять.
- Время хранить с точностью до минуты, локальное (Europe/Warsaw), секунды отбрасывать.
- Ничего не удалять физически при исправлениях без подтверждения; исправление = UPDATE start_ts/end_ts.

## 4. Логика бота (aiogram)

Главное меню — reply-клавиатура, всегда на экране:

```
✅ Пришёл       🌙 Дежурство
🏁 Ушёл         📊 Мои часы
📄 Таблица      ✏️ Исправить
```

Доступ: бот отвечает только chat_id из `ADMIN_CHAT_ID` (плюс, по желанию, второй id владельца). Остальным — «Это личный бот».

### ✅ Пришёл
1. Если уже есть открытый entry → сообщение «Вы уже отметились в HH:MM (отдел). Сначала нажмите 🏁 Ушёл» и стоп.
2. Инлайн-кнопки с тремя отделами.
3. После выбора: INSERT (kind='work', start=сейчас). Ответ: «✅ Записано: 26.07, 09:02, Urologia».

### 🌙 Дежурство
1. Если открыт work-entry → закрыть его текущим временем, сообщить «Дневная смена закрыта: X ч», затем открыть dyzur с этого же момента **тем же отделом** (спросить отдел заново только если work-entry не было).
2. Если ничего не открыто → выбор отдела → INSERT kind='dyzur'.
3. Ответ: «🌙 Дежурство начато: 15:00, Chirurgia Onk.»

### 🏁 Ушёл
1. Если ничего не открыто → «Открытой смены нет. Забыли отметиться? Нажмите ✏️ Исправить».
2. Закрыть открытый entry текущим временем. Посчитать длительность.
3. Ответ: «🏁 Смена закрыта: 8 ч 05 мин (7,87 ч). За месяц: 142,50 ч». После закрытия — вызвать бэкап (раздел 7).
4. Если dyzur закрывается «на следующий день» — это нормально, entry просто пересекает полночь.

### 📊 Мои часы
Сводка: сегодня / текущий месяц. Формат как в Excel: Godziny, Dyżury, Razem (с запятой, 2 знака).

### 📄 Таблица
Сгенерировать .xlsx текущего месяца из базы (раздел 5) и отправить файл в чат.
Инлайн-кнопкой предложить прошлый месяц.

### ✏️ Исправить
Пошаговый диалог (FSM):
1. Выбор: «Добавить пропущенную смену» / «Изменить последнюю запись».
2. Добавить: дата (кнопки «Сегодня/Вчера» + ручной ввод ДД.ММ) → тип (работа/дежурство) → отдел → время от (HH:MM) → время до (HH:MM) → подтверждение с полным текстом → INSERT source='manual'.
3. Изменить последнюю: показать её, спросить новые от/до, подтвердить, UPDATE.
4. Всегда валидировать формат времени; на ошибку — переспросить, не падать.

### Напоминания (APScheduler)
- В 20:00, если открыт work-entry: «Вы ещё на работе? Не забудьте нажать 🏁 Ушёл».
- В 10:00, если dyzur открыт дольше 20 часов: аналогичное напоминание.

### Обработка ошибок
Глобальный error-handler aiogram: любое исключение — в лог `data/bot.log` + сообщение пользователю «Произошла ошибка, данные не потеряны, попробуйте ещё раз». Бот никогда не должен молча умирать на исключении.

## 5. Генератор Excel (`excel.py`) — точная копия шаблона

Файл на один месяц, имя `Grafik_YYYY_MM.xlsx`, один лист. Структура (по фото шаблона):

- **Заголовок** (объединённые ячейки, по центру, жирный):
  `GRAFIK DYŻURÓW – LICZENIE GODZIN (Godziny + Dyżury = Razem)`
- Строка: `Lekar Aliaksandr Pravorau    Miesiąc: <польское название месяца>    Rok: <год>`
- Строка: `Oddział Chirurgii Onkologicznej, Chirurgii Ogólnej, Urologii.`
- **Шапка таблицы** (жирная, с рамками):
  `Dzień | Oddział | Godz. od | Godz. do | Godziny | Dyżury od | Dyżury do | Dyżury godz. | Razem godz.`
- **Строки 1..N** — по одной на каждый день месяца (N = 28/29/30/31), даже пустые.
  - `Dzień` — число дня.
  - `Oddział` — отдел (если в дне были записи; если и work и dyzur — отдел записи; обычно совпадают).
  - `Godz. od` / `Godz. do` — время дневной работы `HH:MM` (в шаблоне встречается и `HH:MM:SS` — писать `HH:MM`). Пусто, если работы не было.
  - `Godziny` — длительность работы в десятичных часах: `минуты/60`, округление до 2 знаков, **запятая** как разделитель (формат ячейки `0,00`). Если работы не было — `0,00`.
  - `Dyżury od` / `Dyżury do` — время дежурства. Дежурство через полночь записывается **целиком в день начала** (например `15:00` → `07:00`, godz. `16,00`) — как в строках 8, 10, 12 шаблона.
  - `Dyżury godz.` — длительность дежурства десятично, иначе `0,00`.
  - `Razem godz.` — формула Excel: `=Eячейка+Hячейка` (Godziny + Dyżury godz.), формат `0,00`.
- **Итог**: строка `SUMA GODZIN (miesiąc):` слева, справа формула `=SUM(...)` по столбцу Razem, жирная, в рамке. В шаблоне пример: `303,52`.
- Оформление: тонкие рамки всех ячеек таблицы, числа по центру/справа как на фото, разумная ширина колонок.

Числовой формат: использовать Excel number format `0.00` — Excel сам покажет запятую в польской/русской локали; **не** писать числа строками с запятой.

Открытые (незакрытые) entries в Excel не попадают.
